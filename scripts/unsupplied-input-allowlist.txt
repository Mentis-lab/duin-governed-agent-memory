# unsupplied-input allowlist -- optional options-object fields that production READS but
# never SUPPLIES. Generated as a baseline on 2026-08-18 so `unsupplied-input-lint` could land as
# a hard gate on NEW instances without waiting for this list to be triaged first.
#
# THIS FILE IS DEBT, NOT CONFIGURATION -- the same contract reachability-allowlist.txt carries.
# Every line is either something to wire or something to delete. Shortening it is the goal, and
# the lint fails on a STALE entry (one that is now supplied) precisely so the list cannot quietly
# become permanent.
#
# WHY THIS LIST EXISTS AT ALL. Two of the most expensive bugs found in August were exactly this
# shape, and both lived in files that `reachability-lint` counted as fully reached:
#   ForkAgentDeps.parentTools        -> every `general` sub-agent ran with zero tools   (ce828a4)
#   WorkflowRunInput.journalDir      -> nothing was journaled, so nothing could resume  (290818c)
# The lint was verified against both: reverting 290818c makes it report them and go red.
#
# TRIAGING A LINE. Two different things are on this list and they deserve different verdicts:
#
#   *Deps.*  (45 entries) -- dependency-injection seams. Production takes a default and only tests
#            inject. That is usually deliberate and correct. It is NOT automatically safe: the
#            parentTools bug was a Deps field whose unsupplied path silently produced the WRONG
#            VALUE ([] instead of '*') rather than a working default. Ask what happens when it is
#            absent, not whether absence is expected.
#
#   everything else (86 entries) -- a caller-intent option nothing on the production path expresses.
#            Each is either a capability with no way to reach it, or a knob that should be deleted.
#
# Nothing here is broken code. It is complete, reviewed, tested work that no production call site
# supplies -- which is exactly why the suite is green and why review never flagged it.
#
# 2026-09-01: the lint now normalises CRLF before matching, so this list is calibrated on the
# as-committed (LF) tree rather than on one machine's checkout. Two Deps seams surfaced that a
# CRLF-masked comment had hidden: BrainHealthDeps.seeds (absent => top-degree note nodes are
# derived, brain-health.ts:420-424) and OrchestratorDeps.embeddings (absent => the RAG embeddings
# service is lazy-loaded, research/index.ts:257). Both absent paths are the intended production
# path, so they are listed as seams, not wired.
