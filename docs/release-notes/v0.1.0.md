The first public release of DUIN, a local-first second brain. Point it at a folder of Markdown
notes and it builds a knowledge graph you can ask, see, and hand to an agent that acts on your
files with your approval.

- **Grounded answers.** Retrieval and reranking run on your machine with bundled encoders;
  answers cite the notes they used and an evidence gate refuses to guess from thin evidence.
- **A graph you can see.** People, projects, decisions and topics from your notes, as a 2D map
  and a 3D field, with open loops, predicted risks and converging threads tracked over time.
- **An agent with real tools, behind approvals.** Files, shell, MCP servers, skills, hooks and
  subagents under a capability allowlist; shell commands, deletes and out-of-vault writes ask
  first. Background loops and autonomy ship off.
- **Works without a key.** Keyless answers from your notes; connect a key for any of the
  supported providers, or a local Ollama.
- **English, Chinese and Japanese** interface.

## What's inside

- The in-process TypeScript brain on `127.0.0.1:8799`: indexing (SQLite + `sqlite-vec` + local
  embeddings), grounding with a cross-encoder reranker, the entity graph, memory with
  provenance, foresight and calibration engines, and the Learn and Govern loops.
- The Brain view (2D map on `cosmos.gl`, 3D field), the Explorer (Memory and Concepts tiers) and
  the Relations panel.
- Providers: OpenAI, Anthropic, Google Gemini, DeepSeek, Moonshot, Zhipu, DashScope (Qwen), xAI,
  Mistral, Groq, DeepInfra, GitHub Models, OpenRouter, and local Ollama. Image generation through
  Seedream, `gpt-image-2` and MiniMax.
- Agent tools: files (vault plus operator-granted folders), shell with per-platform sandboxes,
  web search and fetch, MCP servers (stdio, SSE, HTTP, OAuth), skills and methods, hooks,
  subagents, and an external executor (`delegate_task`, running the DeepSeek Harness in an
  isolated git worktree).
- Governance: approval gates with a deny-first execution token, a catastrophic-command screen, a
  rule-of-two floor, a fail-closed per-action reviewer for unattended surfaces, cost metering
  with a ceiling, and a durable record of every turn.
- Channels (Telegram, Discord, Slack, Feishu, WeCom, DingTalk, Email), all dormant until
  configured; automations and notices; a "Needs you" tab.
- DUIN Brain as an MCP server for other agents (`/exec/mcp`), plus an installable plugin.
- Installers for Windows (x64) and macOS (Apple Silicon); Linux AppImage and `.deb` from CI.

## Known limitations

- **Unsigned installers.** Windows: SmartScreen warns; choose **More info → Run anyway**.
  macOS: ad-hoc signed, not notarized; right-click → **Open** the first time. Verify the SHA-512
  from `latest.yml` before installing. Updates are notify-only until signing lands.
- **Linux is untested.** CI produces the AppImage and `.deb`; the maintainers have not run them.
- **Cloud cost.** With a key connected, a turn is several model calls (answer, retrieval agent,
  extraction), and the first graph build is a pass over the whole vault. Start with a free tier
  or a small model; the chat's token ticker shows what each turn used, and the Agents and
  Executors settings cap what subagents and the external executor may spend. Unattended loops
  stay off until you enable Background autonomy.
- **Languages.** The interface ships in English, Chinese and Japanese only.
- The conversation database is not encrypted; rely on OS disk encryption.
