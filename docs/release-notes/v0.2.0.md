Verify a download against the `sha512` in `latest*.yml` ([how](https://github.com/Mentis-lab/duin-governed-agent-memory/blob/main/docs/getting-started.md#9-verify-a-download)).

The second public release. 0.1.0 could show you a graph and answer from your notes; this one
lets you work the graph — open any node and read what the brain actually knows about it, then
rename and file things without leaving the app.

- **Every derived entity has a card.** Open a person, project or topic in the Explorer and see
  what the brain holds about it, joined together: facts lifted from your notes with superseded
  ones marked, the notes it appears in with the sentence that names it, its typed connections,
  the other names it goes by, and any node that looks like the same thing with a one-click merge.
- **A written description for each entity, from a local model by default.** One or two sentences
  grounded in the card's own material and nothing else; invented names and attributes are dropped.
  A detected Ollama model is used first, so this costs nothing and leaves the machine only if you
  point it at a cloud provider.
- **Organize the vault from the Explorer.** Rename a note, move it into a folder, rename a folder,
  start a new note. A rename rewrites the `[[links]]` that pointed at the old name across your
  notes, and every note rewritten is preserved to `.trash` first.
- **One Home surface instead of five.** Status, Learning, Automations, Background tasks and After
  action fold into a single dashboard that opens on launch and says what needs you.
- **Settings that hold together.** Every page rebuilt on one kit, four controls that had no home
  given one, a schema-guarded settings file with export, import and reset, and a GitHub tab.
- **Claude Fable 5.1 and Gemini 3.8 Flash** in the model picker, with their predecessors kept and
  relabelled as the prior generation.

### Also

- The brain map is faster and reads better: adaptive link ink, notes-first weighting, a label
  budget with community names, remembered camera positions, and physics moved to a worker.
- The model picker's badges follow the interface language instead of showing English inside a
  Chinese or Japanese UI.
- A collapsed right panel keeps a way back at every window width — it used to become unreachable
  below 960px, which an un-maximized window is enough to trigger.

### Removed

- **The 3D brain map**, withdrawn for lag, along with `three` and `three-spritetext`. The 2D
  canvas fallback for machines without WebGL2 stays.

Known limitations are unchanged from 0.1.0 and tracked in
[#10](https://github.com/Mentis-lab/duin-governed-agent-memory/issues/10): installers are
unsigned, updates are notify-only, and recall is on par with plain retrieval rather than ahead
of it. The full list of changes is in [CHANGELOG.md](https://github.com/Mentis-lab/duin-governed-agent-memory/blob/main/CHANGELOG.md).
